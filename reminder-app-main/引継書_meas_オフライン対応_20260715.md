## 対象

- ファイル：`C:\Users\user\Desktop\dev\reminder-app-main\meas.html`
- 公開URL：https://h2ec9629.github.io/reminder-app/meas.html
- GitHubリポジトリ：`h2ec9629/reminder-app`（public, デフォルトブランチ `main`）
- 三相測定の入力＋判定＋履歴共有アプリ（PWA、タブレット運用）

## 今回のセッションでやったこと（時系列）

1. SAVE時に端末へJSONファイルもダウンロードするように追加（`_downloadJson`）
2. LOG画面に「一括DL」ボタン追加：機番ごとにグループ化してJSON一括ダウンロード（`bulkDownloadJson`）
3. 物理キーボード対応：常駐テンキーはそのまま残しつつ、数字キー／Backspace／Enterで同じ処理が走るように配線（`document.addEventListener('keydown', ...)`）。Tabで欄移動した時もフォーカス同期するように修正
4. オプションパネル展開中にLOG画面へ移行したら自動で閉じるように修正（`toggleHist`）
5. オフライン対応：
   - 計算はもともとオフラインで動作（変更なし）
   - LOG画面：オフライン中はGitHub通信を試みず、手元のローカル記録をそのまま表示するように変更
   - SAVE：オンラインかつPAT設定済みの時だけGitHub共有を試行。オフライン／PAT未設定なら`meas_pending_sync`キューに積む
   - オンライン復帰イベント（`window.addEventListener('online', ...)`）で自動的にキューを送信
   - LOG画面のリストに未同期の記録は「未同期」バッジ表示
6. **重要バグ修正**：複数件をまとめて未同期送信する際、1件処理するたびにローカル保存が「今処理中の1件だけ」に上書きされ、他の未送信分が一時的に画面から消える不具合を発見・修正。`_syncNewRecord`のマージ処理に`_loadPending()`（未送信キュー全体）も含めるように修正済み

## デプロイ方法（重要）

- **このフォルダはローカルgitリポジトリになっていない**（`.git`なし）。ローカルファイルを編集しただけでは自動でGitHub Pagesに反映されない
- PAT（GitHubトークン）は `C:\Users\user\Desktop\dev\reminder-app_PAT.txt` にある
- デプロイは GitHub Contents API を直接叩いて実施（`curl`/`urllib`でGET→sha取得→PUT）。リポジトリ：`h2ec9629/reminder-app`、パス：`meas.html`
- 参考：VFAP_gist側にある`github_push.py`と同じ発想だが、reminder-app用の専用スクリプトはまだ無い。作っておくと次回以降ラクかもしれない
- **push後は必ずGitHub側から再取得して内容確認＋`node --check`で構文チェックすること**（ローカルのbashマウント経由の読み込みはキャッシュが古くなることがあるので信用しない。Readツールか、pushしたAPIレスポンス／再取得で確認する）

## 既知の注意点・ハマりどころ

- **Service Worker（`meas_sw.js`）がcache-first**：コードを直しても、端末側は古いキャッシュを見続ける。確認前に必ず「オプション→Update（強制更新）」を押してもらう、またはEdgeでサイトデータ削除
- **GitHub PATはlocalStorageにしか保存されていない**（キー：`ojisan_mailbox_cfg_v1`）。サイトデータを消すとPATも消える → LOG画面が「共有できてるはずなのに古いまま」に見える原因になる。復旧は`reminder-app_PAT.txt`をオプション画面の「テキストファイルから読込」で読み込ませる
- ローカルの`meas.html`をbash経由で`cat`/`diff`すると内容が古いまま返ってくることがある（既知のキャッシュ事故）。Readツールを使うか、GitHub側で検証すること
- Edgeのアドレスバー自動補完で、siteData設定やお気に入りURLが意図しないものに化けることがあった（コード起因ではなくブラウザ側の挙動）
